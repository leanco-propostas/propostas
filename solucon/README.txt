PUBLICAÇÃO NO GITHUB PAGES
--------------------------------------------------------------------
  1. Criar um repositório (público, se necessário).
  2. Enviar o CONTEÚDO desta pasta para a RAIZ do repositório
     (index.html precisa ficar na raiz — não a pasta externa).
  3. Incluir a pasta assets/ completa.
  4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
  5. Aguardar a publicação e atualizar com Ctrl + F5.

  Observações:
  - Todos os caminhos são relativos.
  - As fontes (Barlow Condensed e Inter) vêm do Google Fonts.
  - Não há função de PDF/impressão — a apresentação é por link.
