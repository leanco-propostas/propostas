Publicação no GitHub Pages:
1. Envie index.html, styles.css, script.js e a pasta assets para a raiz do repositório.
2. Settings > Pages > Deploy from a branch > main > /root.
3. Aguarde a publicação e atualize o endereço.

Senha configurada: Lecloa2026

Observação importante:
O controle de acesso é executado no navegador. Ele cria uma barreira prática para o visitante comum, mas não substitui autenticação de servidor. Como o GitHub Pages publica arquivos estáticos, alguém com conhecimento técnico ainda pode acessar o código-fonte. Para proteção real, utilize uma plataforma com autenticação no servidor ou proteção por senha no provedor de hospedagem.
